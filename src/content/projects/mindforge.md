## 项目关系

MindForge 是我个人实现的全栈学习产品，用于展示复杂业务建模、前后端交付、权限边界与发布工程能力。它是产品实现与阶段验证，不是成熟的 AI 测试平台；长期规划中的推荐与 AI 路线尚未落地，不作为已完成能力展示。

## 关键实现

- **业务建模**：以知识图谱组织数学学习内容，诊断沿概念依赖定位薄弱节点。
- **账号与访问控制**：完整的授权生命周期管理，边界行为有真实 API 测试覆盖。
- **学习证据链**：学习行为与结果可回溯，支撑诊断与练习的闭环。
- **Android 学习壳**：WebView 封装的学习客户端，已有阶段验收，未公开分发。

## 分析与验证案例

两个有代表性的验证：

- **诊断提前结束的缺陷**：目录结构中存在没有题目的节点，诊断遍历到这类节点时被误判为"无题可练"，导致诊断提前结束。已修复并加入回归测试。
- **授权生命周期边界测试**：对真实 API 覆盖授权窗口前 / 中 / 后三种状态、到期时间的微秒级边界，以及畸形授权的拒绝路径。

曾通过生产候选环境的验证；当前源码仍在迭代，与当时的验证属于不同阶段。
